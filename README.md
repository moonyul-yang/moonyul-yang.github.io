# Moonyul Yang — Academic Homepage

Website: https://moonyul-yang.github.io/

Content editor: https://app.pagescms.org/

See [관리 안내](ADMIN_GUIDE.md) for adding, editing, hiding, deleting, and restoring content.

The existing design is rendered by GitHub Pages' built-in Jekyll support. Content lives in `_data/*.json`; `.pages.yml` defines the Pages CMS forms. No custom workflow, server, database, or deployment secret is required.

Keep Pages configured to publish from `main` at `/ (root)`. Do not add `.nojekyll`.

This repository and its history are public. Unpublished entries are only hidden from the homepage, not private. Never upload confidential material.
